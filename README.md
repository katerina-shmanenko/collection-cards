# Collection Cards — AI-пайплайн наборов коллекционных карточек

Тестовое задание Playrix «AI-pilled продакшн-продюсер».
Инструмент принимает **тему набора и свободные пожелания продюсера** и выдаёт **3–5 вариантов набора по 10 карточек** в арт-стиле игры — с проверкой качества, превью в окне набора и доработкой по замечаниям обычными словами.

Им сделаны три набора коллекции «Кино» (без золотых карт): **Western**, **Sci-Fi «Starstruck»**, **Spooky «Spooktacular»** — `output/movies/`.

## Как это устроено
- **Claude Code** — оркестратор: придумывает концепции, собирает план набора, генерирует, проверяет каждую картинку и набор целиком, переделывает брак, принимает правки продюсера.
- **Скилл** `.claude/skills/collection-cards/` — знания, вынесенные из анализа игры: правила коллекций, смысловые принципы наборов, style bible, шаблоны промптов, чек-лист QA и скрипты.
- **Генерация — GPT 2.6** (победила в бенчмарке 4 моделей): напрямую через **OpenAI API** или через **Magnific** (MCP). Генератор сменный: можно подключить и внутреннюю модель студии с LoRA (см. «Свой генератор»).
- **Скрипты** делают то, что модель не умеет держать сама: собирают промпт из плана и проверяют правила набора, ставят объект в безопасную зону фрейма (воздух под звёздами редкости), достраивают фон, не меняя одобренную картинку, собирают превью набора в окне.

```
тема + пожелания → концепции (6–8) → план набора (set.json, проверка правил)
→ генерация с 3 референсами категории → вырезка → подгонка в безопасную зону
→ QA (чек-лист + балл) → перегенерация брака → превью во фрейме → правки продюсера
```

## Быстрый старт (для гейм-дизайнера)
1. Установите [Claude Code](https://claude.com/claude-code) (приложение или терминал) и войдите.
2. Установите Python-зависимости (один раз):
   ```bash
   python3 -m pip install --user -r requirements.txt
   ```
3. Подключите генератор — **один из двух**:
   - **OpenAI** (оплата по факту, ≈ $0.06 за карточку): заведите ключ на platform.openai.com → скопируйте `.env.example` в `.env` → вставьте ключ после `OPENAI_API_KEY=`. Ключ никому не пересылайте, `.env` не попадает в git.
   - **Magnific** (кредиты подписки, ≈ 40 кредитов за карточку):
     ```bash
     claude mcp add --transport http magnific https://mcp.magnific.com
     ```
     затем в Claude Code — `/mcp` и вход в Magnific через браузер.
4. Откройте эту папку в Claude Code и напишите своими словами, например:
   > Сделай набор для коллекции «Кино» на тему «Пираты», весело, без страшного, 3 варианта. Сгенерируй пока только вариант A.

   Можно начать бесплатно — «пока только концепции и план, без картинок»: получите `concepts.md` и план набора, а картинки запустите, когда план устроит.
5. Смотрите `output/<коллекция>/<тема>/<вариант>/_frame_preview.png` — набор в окне со звёздами и плашками; все варианты — `index.html`.

## Как просить правки
Говорите обычными словами — скилл переводит их в действие и меняет только названные карточки:

| Вы говорите | Что произойдёт |
|---|---|
| «Карточки 3 и 7 не нравятся» | перегенерация только этих слотов — по одной картинке (несколько вариантов — только если попросите) |
| «У кота нужна выгнутая спина, сделай его лысым» | правка описания карточки в плане и перегенерация |
| «Возьми второй вариант привидения» | замена на кандидата из `_alt/` |
| «Волк крупно, сделай поменьше» | перекадрирование без новой генерации |
| «Убери облака, фон темнее», «стена пыльно-розовая» | правка только фона, объект остаётся тем же |
| «Упирается в звёзды», «много пустоты снизу» | достройка фона и новая подгонка в кадр |
| «Собери финал: из A слоты 1–3, из B…» | папка `final/` с новой раскладкой звёзд и проверкой цветов |

## Стоимость и время (по факту трёх наборов)
- Карточка: ≈ $0.06 (OpenAI) или 40 кредитов (Magnific), ~30 с; достройка/правка фона ≈ $0.07 / 65 кредитов.
- Вариант набора из 10 карточек с проверкой: ~5–10 минут машины и ≈ $1 без учёта правок.
- Итог по проекту — в `docs/WORKLOG.md`.

## Свой генератор (например, внутренняя LoRA студии)
Генерация — один сменный шаг пайплайна. Всё остальное — идеи и план набора, проверка правил (редкость, категории, масштабы, повторы в коллекции), вырезка, безопасная зона под звёздами, QA, превью в окне и правки продюсера обычными словами — от генератора не зависит.

```bash
python3 .claude/skills/collection-cards/scripts/generate_set.py output/<коллекция>/<тема>/<вариант> --generator lora
```
- `--generator openai` (по умолчанию), `lora` или путь к любому скрипту с тем же контрактом: `--prompt-file`, `--category`, `--out`, `--n`, `--quality` на входе, JSON `{"saved": [...]}` на выходе.
- `lora_generate.py` — готовый переходник к **ComfyUI**: в `.env` указать `LORA_API_URL` (сервер), `LORA_WORKFLOW` (workflow, сохранённый через «Save (API Format)», с метками `%PROMPT%`, `%NEGATIVE%`, `%SEED%`, `%WIDTH%`, `%HEIGHT%`, `%BATCH%`, `%STEPS%`, `%CATEGORY%`), при необходимости `LORA_TRIGGER`. LoRA выбирается в самом workflow.
- Стиль держит LoRA, поэтому длинный блок стиля из промпта по умолчанию отбрасывается: остаются настроение, объект, фон, камера и запреты. Референсы не отправляются (при желании — IP-Adapter в workflow).
- Достройка фона (`extend_bg.py`) пока идёт через OpenAI; для полностью внутреннего контура её заменяет outpainting той же модели.

Другие варианты сборки инструмента (Magnific Spaces, форма n8n, другие модели) и когда какой выбирать — `docs/ALTERNATIVES.md`.

Зачем это студии: стиль точнее, чем через 3 референса (LoRA обучена на собственном арте игры); арт и наброски не уходят во внешние сервисы; дешевле на больших объёмах и без зависимости от внешних API.

## Референсы
Карточки игры и материалы ТЗ — собственность Playrix, в публичный репозиторий они не входят.
- **Без них инструмент работает сразу**: скилл берёт запасные style-референсы — 12 наших утверждённых карточек из наборов «Кино» (`.claude/skills/collection-cards/fallback_refs/`, по 3 на категорию).
- **Для максимального попадания в стиль** положите оригинальные карточки игры в `references/cards_hq/` с именами из `references_local.json` (например `references/cards_hq/cat1_air/grad_cap.png`) — скилл сам переключится на них. Все наборы в `output/movies/` сгенерированы на оригинальных референсах.
- Сравнение с картинками игры (`docs/comparison/*game_vs_ours.png`) — на Miro-доске.

## Ограничения
- Модель не держит размер и положение объекта — это делают скрипты; иногда нужен ручной ключ (`--margins`, `--center mass`).
- Точечная правка одной детали есть только в Magnific; в OpenAI — перегенерация карточки или правка фона.
- Переходник `lora_generate.py` проверен на имитации сервера ComfyUI, не на реальной модели студии: workflow и метки нужно настроить под свой сервер.
- ID референсов в Magnific привязаны к аккаунту; на новом аккаунте их нужно загрузить заново (файлы — в `references_local.json`).
