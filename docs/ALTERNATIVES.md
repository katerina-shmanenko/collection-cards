# Альтернативные способы собрать инструмент

Мы выбрали **Claude Code + скилл + GPT 2.6 (OpenAI API или Magnific MCP)**. Ниже — варианты, которые рассматривали, и когда какой выбирать. Подробности разведки — `RESEARCH_TOOLS.md`.

| Вариант | Как работает | Плюсы | Минусы | Когда выбирать | Статус |
|---|---|---|---|---|---|
| **Claude Code + скилл** (выбран) | агент читает правила, сам строит план набора, генерирует, проверяет, правит по словам продюсера | вся логика набора (смысл, редкость, категории, QA) в одном месте; правки обычными словами; генератор сменный | нужен Claude Code; гейм-дизайнер работает в чате, а не в форме | основной инструмент для продюсера и гейм-дизайнера | сделано, 3 набора «Кино» |
| **Внутренняя модель + LoRA (ComfyUI)** | тот же скилл, но генерация через `--generator lora` на сервере студии | стиль точнее (LoRA обучена на арте игры), арт не уходит наружу, дешевле на объёмах | нужен обученный LoRA и workflow; композицию может понадобиться держать ControlNet | если в студии уже есть ComfyUI и LoRA под игру | переходник `lora_generate.py` готов, проверен на имитации сервера |
| **Полностью локальный стек** (Qwen через Strata / LM Studio + ComfyUI) | локальная языковая модель (Qwen3.8-Flash-Next через движок Strata или LM Studio, умеет смотреть на картинки) — «мозг» вместо Claude; картинки — локальные модели в ComfyUI | бесплатно за картинку, всё на своём компьютере, приватно | нужна видеокарта 8–12 GB и 32–64 GB RAM (на Mac медленно); без LoRA под игру стиль хуже (Qwen Image проиграл GPT 2.6 в бенчмарке); локальный агент слабее Claude в плане набора, проверках и правках на русском; данные о модели — в основном из блогов | если в студии есть мощные машины и LoRA под игру; генерацию можно подключить к нашему скиллу через `--generator lora` | разведано 11.11, не тестировали |
| **Magnific Spaces / Flows** | генерация собирается узлами в интерфейсе Magnific, запуск из Claude Code через `spaces_run` / `flows_run` | художник настраивает цепочку визуально, без кода | логика набора (план, проверки, безопасная зона) всё равно вне Spaces; параметры запуска не задокументированы; кредиты списываются | если цепочку генерации ведёт художник в Magnific | разведано: запуск из MCP возможен, свой Space под карточки не строили |
| **n8n — форма для гейм-дизайнера** | веб-форма (тема, пожелания) → LLM по API → генератор → папка на Drive | не нужен Claude Code: ссылка на форму и всё | LLM нужен по API-ключу; правки словами и QA слабее, чем в агенте; ещё один сервис | «кнопка» для тех, кто не работает в Claude Code | разведано (облако €20–24/мес, есть триал), не строили |
| **Другие модели в том же скилле** | Nano Banana 2.1, Seedream 5, Flux.2 — через Magnific | Nano Banana 2.1 — второе место в бенчмарке; Flux.2 / Seedream берут до 10–14 референсов | по бенчмарку хуже держат стиль игры и точный кадр, чем GPT 2.6 | запасной генератор, если GPT 2.6 недоступен | бенчмарк: `output/_benchmark/` |

## Как их можно сочетать
Скилл остаётся «мозгом» (смысл набора, правила, QA, правки), а генератор и вход меняются:
- генерация: **OpenAI / Magnific сейчас → LoRA студии** через `--generator lora`;
- «мозг»: **Claude сейчас → локальная модель (Qwen через Strata / LM Studio)**, если нужен полностью внутренний и бесплатный контур — ценой качества плана и правок;
- вход: **чат в Claude Code сейчас → форма n8n** для тех, кто не работает в Claude Code (форма запускает тот же пайплайн).
