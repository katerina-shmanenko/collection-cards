# Правила коллекций (из ТЗ, без интерпретаций)

## Структура
- **Коллекция** — набор тематических карточек, которые игрок собирает в разных игровых активностях. 16 наборов по 10 карт.
- Коллекция посвящена одной широкой теме: «Кино», «Путешествие», «Лето» и т.п.
- **Набор (сет)** — подтема коллекции. Наборы разнообразны и не повторяются. Пример для «Лета»: «Пляж», «Сад», «Спорт».
- **Карточки** подбираются под тему набора. Пример для «Пляжа»: надувной мяч, замок из песка, пляжная сумка.
- Карточки имеют разную **редкость** (1–5 звёзд). Редкость НЕ влияет на визуальное отображение предмета.
- **Золотые карточки** — ключевые персонажи коллекции в ироничной эмоциональной ситуации, не больше 2 персонажей. 16-й сет — гранд-сет только из золотых карт. *(В этом задании золотые не делаем.)*

## Категории арта (в каждом сете присутствуют все 4, вне зависимости от редкости)
1. **Объект в воздухе.** Без мелких деталей. Фон — однотонный с градиентом или простой узор (полосы, повторяющиеся объекты, ровный цвет, световые лучи).
2. **Объект на простой поверхности.** Без мелких деталей. Позади — вертикальная поверхность: простая/однотонная с градиентом или простой узор.
3. **Объект на реалистичной поверхности.** Объёмный фон: объект стоит/вписан в простую реалистичную поверхность, позади — простая вертикальная поверхность или узор.
4. **Объект в реалистичной обстановке**, но остаётся центральным.
5. *(Золотые)* Сюжетная картинка с фоном категории 4, 1–2 персонажа, простая сценка.

## Примеры из референсов
- Категория 1: Bottle, Pizza, Honey, Fan Fold, Lollipop
- Категория 2: Tea Cup, Mojito, Sunglasses, Lemon tree (Potted), Beach Bag
- Категория 3: Bumpers, Cheese Plate, Coffee Pot, Pie, Basket
- Категория 4: Field Ball, Lighthouse, Antiquity, Sunblock (lifeguard), Coaster

## Сеты коллекции Summer (пример)
Gardens, Sports, Finals, Amusement, Coolness, Countrystead.
